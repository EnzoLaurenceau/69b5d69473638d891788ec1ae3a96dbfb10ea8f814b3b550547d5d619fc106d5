# 📋 Templates — Vault

> Templates pour les notes du vault. Copier-coller quand on crée une nouvelle note.

## Template Note d'Agent

```markdown
# Agent: [Nom]

## Performance
- Score moyen: X/10
- Tendance: improving / stable / declining
- Dernière tâche: [description]

## Historique
| Date | Tâche | Score | Tokens | Notes |
|------|-------|-------|--------|-------|
| ... | ... | ... | ... | ... |

## Prompt Adjustments
- Ajustement 1
- Ajustement 2

## Observations
- Observation 1
- Observation 2

#agent #performance
```

- Lignes: X-Y
- Type: function / class / module

...

## Callers

- caller2 → this_function

## Calles

#code-graph #symbole
