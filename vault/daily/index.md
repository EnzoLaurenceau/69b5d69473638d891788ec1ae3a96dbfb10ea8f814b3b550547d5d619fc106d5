# 📅 Daily — Journal

> Fragments de pensée, décisions, TODOs quotidiens.
> Un fichier par jour, liens vers les sujets.

## 📋 Template

```markdown
# YYYY-MM-DD

## 🎯 Objectifs du Jour
- [ ] Objectif 1
- [ ] Objectif 2

## 📝 Notes
- Note 1
- Note 2

## 🔗 Liens
- [[../forge/index|Forge]]
- [[../personal/index|Personnel]]

## ✅ Done
- [x] Tâche terminée

#daily #YYYY-MM-DD
```

## 📂 Archives

Les fichiers daily sont nommés `YYYY-MM-DD.md`.
Ils s'accumulent ici et sont liés aux sujets correspondants.
