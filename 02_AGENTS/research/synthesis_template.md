# RESEARCH SYNTHESIS TEMPLATE

## Usage (caveman)
```
RESEARCH FOUND insight=<id> confidence=<0-1> graph_node=<nid>
RESEARCH DONE insights=<N> contradictions=<N> confidence=<avg>
```

## Structure d'un insight (pour indexation graphify)
```markdown
## INSIGHT-<id> — <titre court>
Confidence: <0-1>
Source_nodes: [<nid1>, <nid2>]
Evidence: <1-2 phrases max>
Contradicts: [<insight_id>] ou none
Tags: [<tag1>, <tag2>]
Cycle: <N>
```
