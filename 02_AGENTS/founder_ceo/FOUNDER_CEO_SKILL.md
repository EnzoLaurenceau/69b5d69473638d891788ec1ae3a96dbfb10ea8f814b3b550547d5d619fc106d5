## PRINCIPES FONDATEURS — Distillés de 100k+/mois

### PIETER LEVELS ($176k/mois · NomadList · PhotoAI · InteriorAI)

**Règle 1 — Ship en 30 jours ou abandon**
Aucun projet ne dépasse 30 jours avant le premier revenu.
Si pas de revenu en 30j → pivoter ou tuer.

**Règle 2 — Tech ennuyeuse, marges maximales**
Stack : PHP ou Next.js + SQLite/Postgres + Stripe.
0 micro-services. 0 Kubernetes. 1 serveur suffit jusqu'à 100k/mois.
Chaque layer de complexité = moins de marge = moins de liberté.

**Règle 3 — SEO first, ads last**
Tout le trafic = organique au début.
1 article de blog SEO bien fait > 1000€ de Google Ads.
Construire l'actif (Google ranking) pas louer l'audience (ads).

**Règle 4 — Automation totale des opérations**
Si tu fais quelque chose manuellement 2 fois → automatiser.
L'objectif : réveillage le matin avec des revenus qui ont tourné la nuit.

**Règle 5 — Build in public**
Twitter/X : partager les revenus, les galères, les apprentissages.
La transparence = trust = conversion.
"$176k MRR ce mois" → des milliers de followers → prospects entrants.

### ALEX HORMOZI (Acquisition.com · $150M+ ARR)

**La Grand Slam Offer (formule)**
```
Valeur perçue = (Résultat rêvé × Probabilité perçue)
               ÷ (Délai × Effort + Sacrifice)

→ Augmenter les 2 numérateurs
→ Réduire les 2 dénominateurs
→ Résultat : offre si bonne qu'ils se sentent stupides de refuser
```

**Structure d'une offre à 100k+/mois :**
1. Identifier le désir profond (pas le produit — le résultat)
2. Lister toutes les raisons de ne PAS acheter
3. Créer une solution pour CHAQUE objection
4. Empiler les bonifications jusqu'à ce que la valeur perçue > prix × 10
5. Ajouter une garantie qui inverse le risque complètement

**Value Ladder (architecture revenue)**
```
FREE  → Lead magnet (résout 1 problème précis, gratuitement)
LOW   → Produit entrée (27€-97€) → valide l'acheteur
MID   → Produit core (297€-997€) → génère les marges
HIGH  → Done-for-you (2000€+) → maximise LTV
```

**Core Four (acquisition clients)**
1. Warm outreach (DMs aux followers existants)
2. Contenu gratuit (Twitter/YouTube → inbound)
3. Cold outreach (DMs ciblés à des inconnus qualifiés)
4. Paid ads (seulement quand les 3 premiers marchent)

**Stack ultra-rentable**

→ Produit en ligne en 24h. Pas en 3 mois.

**Anatomie d'une landing page qui convertit (Marc Lou)**
```
[HERO]         → Titre : bénéfice exact en 5-8 mots
               → Sous-titre : pour qui + résultat + en combien de temps
               → CTA : 1 seul bouton, couleur contrastée

[PROBLÈME]     → Agiter la douleur actuelle (3-4 bullets)
               → "Tu passes des heures à faire X à la main..."

[SOLUTION]     → Montrer le produit en action (démo GIF ou vidéo)
               → 3 features max avec bénéfice, pas spec technique

[SOCIAL PROOF] → Chiffres exacts : "2 847 devs utilisent déjà"
               → 3-5 témoignages avec photo + prénom + titre
               → Logos clients si B2B

[PRICING]      → 1-2 plans max. Pas 4. Jamais 6.
               → Plan recommandé visuellement distinct
               → Prix barré si promotion

[FAQ]          → 5-7 objections principales (pas de prix, sécurité, etc.)

[CTA FINAL]    → Répéter le bénéfice + urgence douce + 1 bouton
```

**Métriques cibles (Marc Lou standards)**
- Conversion visitor → trial : ≥ 3%
- Conversion trial → paid : ≥ 20%
- Churn mensuel : ≤ 5%
- MRR growth MoM : ≥ 15%
